# 校园万能小助手：第一阶段交付与后续路线

用户已确认：先供本人使用，优先建设校园问答与办事导航；所有开发在原项目进行。

## 第一阶段可用功能

- 顶部「办事导航」：学生请假、学籍与证明、选课考试、奖助资助、校园卡、图书借阅、宿舍报修、校园网账号、就业招聘共 9 类事项。
- 事项详情区展示已收录的原文片段、官网链接、咨询联系人和待确认细则；没有正式资料的事项显示资料缺口，不编写假流程。
- 部门/学院/岗位查询直接解析官网办公电话簿原文，共 277 条联系人；支持部门加岗位查询（例如“教务处学籍科电话”）。联系人不等于审批人。
- Agent 新增 find_campus_contact 与 get_campus_service 工具；后者支持学院参数，以查询本人学院的咨询联系方式。
- 问答来源面板：每轮保存检索参考资料、原文网址、入库时间及能识别的发布时间，重新打开对话仍可查看。检索命中不等于全部结论已核实。
- 检索改进：标题加权、校园用语别称、主题/办理意图限制和学院/本科研究生适用范围约束。缺乏相关资料时允许空结果，不用校园活动新闻回答补卡问题，不用电话号码回答开馆时间。
- 旧的无原文链接整理版电话簿保留供人工核对，退出自动检索。官网原始号码簿作为联系信息依据。
- 新补入信息服务大厅常见问题、学生入网指南 2 份官网资料；入网指南是历史页面，不能假定仍是最新办理规则。当前知识库共 654 份文档、2758 个切块。
- 存储兼容：messages 增加 source_refs 列；启动会为既有数据库补列，不清空历史消息。

## 使用方式

访问 http://127.0.0.1:8300/，刷新后点顶部「办事导航」。选择事项查看资料，也可输入“应用科技学院”或“学籍科”查找咨询联系人。点击「向助手询问此事项」会进入当前对话提问。回答下方的「检索参考资料」可展开并查看官网或已收录原文。

## 验证和当前边界

- Python 33 项测试：31 通过，2 项既有 PDF 可选依赖测试跳过。
- Node 4 项通过，涵盖设置保存和来源链接安全；修改过的 Python 与前端 JavaScript 语法检查通过。
- API 验证涵盖 9 类导航、277 联系人、学院筛选、未知事项 404、缺失资料空结果和来源随对话留存；真实 DeepSeek 验证结果见 output/campus_help_live_final_report.json。
- 本机 Edge 无界面浏览器的 GPU 进程启动失败，未完成桌面/手机截图和实际浏览器交互验证；留存 output/edge-review*.stderr.log，不能把静态检查当作视觉验收。
- 目前个人课表、成绩、真实空教室占用等仍未接入；校园卡补办收费/窗口、各学院请假审批权限等细则仍需正式资料。
- 当前检索为本地启发式方法，来源提示和适用范围规则减少误答，不能保证每个问题都能找到答案。官网资料为采集快照，不是实时校务接口。

## 后续阶段

1. 按高频事项补齐各部门的现行办事指南、表格、入口和发布日期，维护资料有效性，并用真实问题做验收。
2. 增加个人待办、学期安排、考试与截止事项管理，再接通知渠道完成提醒。
3. 根据学校允许的接口或导入格式，接入个人课表、成绩和考试安排；不在聊天框收集教务密码。
4. 本人使用稳定后，再建设账号登录、个人数据隔离与多人部署。

## 原项目文件

backend/services.py：办事导航和官网电话簿解析。
backend/retrieval_rules.py、backend/rag.py：相关性与来源元数据。
backend/agent.py、backend/tools.py：带来源的回答和可调用办事工具。
backend/db.py、backend/main.py：兼容升级与 API。
frontend/index.html：办事导航、联系人查询和来源面板。
tests/test_campus_help.py、tests/campus-help.test.cjs：新增回归用例。
